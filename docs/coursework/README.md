# Материалы версии 1.0

Версия 1.0 (сентябрь 2026) была учебным проектом по дисциплине «Тестирование, верификация и валидация программного обеспечения» в РТУ МИРЭА. Документы собраны здесь в том виде, в каком были сданы:

- [TZ.md](TZ.md) — техническое задание;
- [USER_GUIDE.md](USER_GUIDE.md) — руководство пользователя версии 1.0;
- [ARCHITECTURE.md](ARCHITECTURE.md) — устройство версии 1.0;
- [DEPLOY.md](DEPLOY.md) — развёртывание версии 1.0;
- [reports](reports) — отчёт по практической работе;
- [testing](testing) — автотесты и протокол тестирования продукта другой команды.

Исходный код версии 1.0 — тег [v1.0.0](https://github.com/APELSINKos/personal-assistant-bot/tree/v1.0.0). Текущая версия устроена иначе: см. [архитектуру](../ARCHITECTURE.md). Команды в [DEPLOY.md](DEPLOY.md) относятся к коду версии 1.0: после `git clone` нужен `git checkout v1.0.0` (старый адрес репозитория перенаправляет сюда). Автотест из [testing](testing) — тот же, что в версии 1.0, и запускается из своей папки без перехода на тег; в его описании исправлена только строка запуска.
