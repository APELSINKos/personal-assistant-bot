## Что умеет

| | |
|---|---|
| 📱 **Mini App** | Всё то же в приложении внутри Telegram: экран «Сегодня», погода на сутки и неделю, календарь с парами и напоминаниями, привычки в одно касание, деньги с диаграммами, заметки с чек-листами и настройки. Тема и язык — как в Telegram |
| 🌤 **Погода с советами** | Не только градусы: через сколько минут начнётся дождь или снег, похолодает ли к вечеру, не слишком ли ветрено или холодно, хороший ли день для велосипеда. Прогноз по часам и на неделю — в том же сообщении, для домашнего города и ещё четырёх, и погода на дорогу к парам и обратно |
| ☀️ **Утренняя сводка** | Бот сам пишет в выбранное время по часовому поясу вашего города: погода сейчас и на пары, дела на сегодня, привычки, вчерашние траты, курсы |
| 📅 **Мой день** | Всё важное на сегодня одним сообщением — с закреплёнными заметками, а вечером и с погодой на завтра |
| ⏰ **Напоминания** | Пишите как человеку: «завтра в 9 купить молоко», «через 20 минут чай», «по будням в 7:30 зарядка». Повторы по дням недели, раз в две недели и раз в месяц — по поясу вашего города; в пришедшем напоминании кнопки «+10 мин», «+1 ч», «Завтра», «✓ Готово» |
| 🎓 **Расписание пар** | Группа МИРЭА по названию, ссылка на любой календарь (`webcal://`, `https://`) или файл `.ics`: пары и номер недели в календаре приложения, «Моём дне» и утренней сводке, обновление само каждые 6 часов, напоминание за 5–60 минут до пары — по желанию |
| 🎯 **Привычки** | Отметка в одно касание, цель — каждый день или несколько раз в неделю, серия и рекорд, процент за год, карта года, свои эмодзи и цвет; карточкой со статистикой можно поделиться в любом чате |
| 📝 **Заметки** | Чек-листы с галочками, поиск без учёта регистра и «ё», закрепление важного наверх; ссылки сохраняются и нажимаются в приложении. Сообщение, которое бот не понял, становится заметкой одной кнопкой «📝 В заметки» |
| 💰 **Финансы** | Трата записывается одной фразой прямо в чате: «кофе 250», «вчера такси 300», «+5000 стипендия». Категория угадывается по словарю, а поправленная — запоминается. Бюджет на месяц и по категориям предупреждает на 80 % и 100 %, отчёт месяца приходит картинкой, курсы ЦБ — с графиком за 30 дней и конвертером |
| 🌐 **Два языка** | Русский и английский: язык берётся из Telegram и меняется в настройках |

## Mini App

Кнопка «Открыть» у поля ввода открывает приложение прямо в Telegram — тот же аккаунт и те же данные, что в чате: добавленное в приложении сразу видно в боте, и наоборот.

| Экран | Что там |
|---|---|
| **Сегодня** | Большая дата, погода с советами (касание открывает экран «Погода»), пары с погодой на дорогу и дела на сегодня, привычки с отметкой в одно касание, траты дня с полосой бюджета, закреплённые заметки, курсы и лучшая серия. Потяните вниз — данные обновятся |
| **Погода** | Чипы городов — домашнего и дополнительных; сейчас с ощущаемой температурой, порывами ветра, влажностью и всеми советами, лента на 24 часа с кривой температуры, 7 дней с полосами диапазона, восход и закат |
| **Календарь** | Неделя полосой с точками и номером недели, подпись дня «Сегодня · вторник, 29 сентября», месяц по тапу; пары, напоминания и повторы по дням, правка и удаление, новое напоминание фразой или по полям |
| **Привычки** | Список с прогрессом недели и отметкой по кругу ⬜ → ✅ → ❌, как в боте. У каждой привычки свой экран: серия, рекорд, процент за год, карта года (неделя открывает свой месяц), отметки за прошлые дни, цель, эмодзи и цвет; «Поделиться» отправляет карточку в любой чат |
| **Заметки** | Поиск над списком, закреплённые сверху, чек-листы с галочками и прогрессом, адреса в тексте нажимаются; редактор со счётчиком символов, перед выходом с несохранённым текстом приложение спросит |
| **Деньги** | Месяц со стрелками: сколько потрачено и сколько осталось на каждый день, кольцо по категориям (касание показывает записи категории), траты по дням и все записи — правка касанием, удаление смахиванием. Новая запись, бюджеты, свои категории с эмодзи, курсы любой валюты ЦБ за 30 дней и конвертер |
| **Ещё** | Города — домашний и до четырёх дополнительных, расписание пар (группа, ссылка или файл, напоминания о парах), утренняя сводка, язык, валюта, источники данных, версия |

Тёмная и светлая тема повторяют Telegram, «Назад» и главная кнопка — родные кнопки Telegram, действия отзываются вибрацией. Приложение работает только внутри Telegram: каждый запрос несёт подпись Telegram, и сервер её проверяет.

## Как устроено

```mermaid
flowchart LR
    user([Пользователь]) <--> tg[Telegram]
    tg <-->|long polling| bot["assistant.bot<br/>aiogram 3"]
    tg -->|Mini App| web["webapp<br/>React + TypeScript"]
    web -->|"HTTPS, подпись initData"| caddy[Caddy]
    caddy --> api["assistant.api<br/>FastAPI"]
    bot --> core["assistant.core<br/>правила и данные"]
    api --> core
    scheduler["Планировщик<br/>напоминания, сводка, расписания"] --> core
    scheduler --> tg
    core --> db[("SQLite (WAL)")]
    core --> meteo[Open-Meteo]
    core --> cbr[ЦБ РФ]
    core --> ical["Календари<br/>МИРЭА, iCal"]
```

- **Фразы без ИИ.** Разбор «завтра в 9», «через 20 минут», «раз в две недели по средам» — набор правил на русском и английском с сотней с лишним табличных тестов; бот ничего не создаёт, пока вы не подтвердите карточку.
- **Траты тоже без ИИ.** «кофе 250» разбирают правила и словарь из двух сотен основ слов, а память пользователя помнит, куда он перекладывал записи. Фразы напоминаний разбираются раньше, единицы и время («2 литра», «встреча в 9») тратой не считаются, а каждая записанная трата сразу приходит с кнопкой «Отменить».
- **Ядро отдельно от Telegram.** Правила — лимиты, серии привычек, разбор времени, советы погоды — живут в `assistant.core` и покрыты тестами. Бот только разбирает ввод и оформляет ответы, API приложения вызывает те же сервисы — поэтому правила в чате и в приложении одни и те же.
- **Приложению верят только по подписи.** API пускает к данным, только если initData подписана Telegram токеном бота и не старше суток; пользователь берётся из подписи, чужой id — 404. Исключение одно — картинка карточки: её Telegram скачивает сам, по ссылке с токеном (ниже). Ошибки — в формате problem+json, не больше 120 запросов в минуту.
- **Расписание из любого календаря.** Группа МИРЭА ищется по названию в справочнике, который сервер сам собирает по календарям групп; ссылка или файл `.ics` разбираются тем же кодом. Пары разворачиваются на четыре месяца вперёд и показываются по поясу вашего города; если источник недоступен, остаётся прежнее расписание с пометкой «данные от …».
- **Прогноз одним запросом.** Open-Meteo отдаёт на город сразу всё: погоду сейчас, осадки по 15 минут, неделю по часам и по дням. Моменты приходят секундами Unix и переводятся по поясу города, поэтому подписи часов не съезжают после перехода на зимнее время. Ответ проверяется до того, как попасть в кэш на 10 минут; одновременно — не больше двух запросов, после сбоя — минута паузы, а «Мой день», сводка и «Сегодня» без погоды всё равно приходят.
- **Чек-лист в чате и в приложении.** Пункты — отдельные строки в базе, поэтому отметка в чате и отметка в приложении не затирают друг друга. Кнопка пункта не переключает его, а ставит обещанное состояние: кнопка старой карточки не отменит отметку из приложения. Поиск заметок сворачивает регистр и «ё» одинаково в Python и TypeScript, и обе стороны проверяет одна таблица случаев.
- **Картинки рисуются на сервере.** Pillow рисует карточку привычки, отчёт месяца и курсы за 30 дней — JPEG 1080×1350 из шрифтов и эмодзи, которые лежат в репозитории, поэтому одни и те же данные дают одну и ту же картинку на любой машине. Карточку привычки из приложения Telegram забирает по ссылке со случайным 256-битным токеном; она хранится, пока Telegram может её запросить, но не дольше 7 дней, у пользователя — не больше 10 карточек. Картинок — не больше 6 в минуту на пользователя.
- **Графики в приложении — свои.** Кольцо по категориям, траты по дням, линия курса и кривая температуры — SVG без библиотек; у каждого графика есть подпись для экранного диктора, а цифры продублированы в легенде и списках.
- **Ссылки не ведут внутрь сервера.** Календарь по ссылке скачивается только с публичных адресов: сервер сам разрешает имя, проверяет каждый адрес и каждый редирект и подключается к проверенному IP — до 2 МБ и 10 секунд, не больше трёх скачиваний или разборов календаря в минуту на пользователя (в боте и в приложении отдельно). Вдобавок службам systemd закрыты частные сети, адреса link-local и CGNAT `100.64.0.0/10` (loopback остаётся открытым).
- **Время без сюрпризов.** Все моменты хранятся в UTC, «сегодня» считается по часовому поясу города, переходы на летнее время учтены.
- **Доставка с повторами.** При ответе 429 бот ждёт столько, сколько попросил Telegram; при сбое сети повторяет через 30 с, 1 мин, 5 мин, 15 мин, 1 ч и 3 ч; тех, кто заблокировал бота, не беспокоит.
- **Диалоги в базе.** Незаконченный ввод переживает перезапуск, а кнопка меню посреди ввода просто открывает раздел.
- **Автодеплой.** После зелёного CI коммит из `main` уходит на сервер. Приложение собирается, пока работает прежняя версия; если бот или API не поднялись, скрипт возвращает прежний код, базу и сборку приложения.

## Запуск для разработки

```bash
uv sync
cp .env.example .env                # впишите BOT_TOKEN тестового бота
uv run alembic upgrade head
uv run python -m assistant.bot      # бот
uv run python -m assistant.api      # API для приложения, 127.0.0.1:8000
cd webapp && npm ci && npm run dev  # приложение в браузере
```

Настройки читаются из переменных окружения или файла `.env`, список — в [.env.example](.env.example). Чтобы открыть приложение в обычном браузере, нужна подписанная initData: её печатает `scripts/dev_init_data.py` токеном тестового бота. Проверки: `uv run pytest`, `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy`; для приложения — `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`. Подробнее — в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
